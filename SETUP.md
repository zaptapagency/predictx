## Local Development

### 1. Clone and Setup

```bash
# Clone the repository
git clone https://github.com/yourusername/universalpredict.git
cd universalpredict

# Copy environment file
cp .env.example .env

# Edit .env with your settings (optional for local dev)
# At minimum, update LIGHTGBM_REPO_URL and LIGHTGBM_REPO_BRANCH
nano .env
```

### 2. Start Services with Docker

```bash
# Build and start all services
docker-compose up -d

# Check services are running
docker-compose ps

# View logs
docker-compose logs -f backend
docker-compose logs -f frontend
docker-compose logs -f postgres
```

### 3. Access the Application

- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:8000
- **API Docs**: http://localhost:8000/docs
- **ReDoc**: http://localhost:8000/redoc
- **Database**: localhost:5432 (user: universalpredict, password: password)
- **Redis**: localhost:6379

### 4. Initialize Database (if needed)

```bash
# Run migrations
docker-compose exec backend python scripts/setup_db.py

# Load sample data
docker-compose exec backend python scripts/load_sample_data.py
```

### 5. Stop Services

```bash
# Stop all services
docker-compose down

# Stop and remove volumes
docker-compose down -v
```

## Add Your Models

### Model Directory Structure

```
models/
├── v1.0/
│   ├── universal_model.pkl
│   ├── universal_model_metadata.json
│   └── feature_names.txt
├── v1.1/
│   └── universal_model.pkl
└── adapters/
    ├── saas_adapter.pkl
    ├── retail_adapter.pkl
    └── healthcare_adapter.pkl
```

### Metadata JSON Format

```json
{
  "version": "1.0.0",
  "training_date": "2024-01-15",
  "accuracy": 0.92,
  "feature_count": 45,
  "feature_names": [
    "feature_1",
    "feature_2",
    "feature_3"
  ]
}
```

### Upload Your Models

**Option 1: Add to Your GitHub Repo**

```bash
# In your models directory
git add models/
git commit -m "Add trained LightGBM models"
git push origin main
```

**Option 2: Update Docker Build Args**

Edit `docker-compose.yml`:

```yaml
backend:
  build:
    args:
      LIGHTGBM_REPO_URL: https://github.com/yourusername/your-lightgbm-repo.git
      LIGHTGBM_REPO_BRANCH: main
```

**Option 3: Mount Local Models (Development)**

Edit `docker-compose.yml`:

```yaml
backend:
  volumes:
    - ./backend:/app/backend
    - /path/to/your/models:/app/lightgbm-repo/models  # Add this line
```

## Testing

### Backend Tests

```bash
# Run all tests
docker-compose exec backend pytest tests/ -v

# Run with coverage
docker-compose exec backend pytest tests/ -v --cov=app

# Run specific test
docker-compose exec backend pytest tests/test_api.py -v
```

### Frontend Tests

```bash
# Run all tests
docker-compose exec frontend npm test

# Run with coverage
docker-compose exec frontend npm test -- --coverage
```

### Manual API Testing

```bash
# Test health check
curl http://localhost:8000/health

# Make a prediction (requires models loaded)
curl -X POST http://localhost:8000/api/predictions \
  -H "Content-Type: application/json" \
  -d '{
    "vertical": "saas",
    "prediction_type": "churn",
    "features": {
      "feature_1": 1.0,
      "feature_2": 10
    }
  }'

# Test file upload
curl -X POST http://localhost:8000/api/upload \
  -F "file=@data.csv"
```

## Deployment

### Deploy to Railway

#### Step 1: Create Railway Account

1. Go to https://railway.app
2. Sign up with GitHub
3. Create a new project

#### Step 2: Add Secrets

In Railway dashboard:

```
RAILWAY_TOKEN: (copy from railway.app/account/tokens)
DATABASE_URL: (auto-generated by Railway)
REDIS_URL: (auto-generated by Railway)
JWT_SECRET_KEY: (generate a secure key)
```

#### Step 3: Deploy

```bash
# Install Railway CLI
npm install -g @railway/cli

# Login
railway login

# Deploy
railway up
```

#### Step 4: View Logs

```bash
railway logs -f
```

---

### Deploy to DigitalOcean

#### Step 1: Create DigitalOcean Account

1. Go to https://digitalocean.com
2. Create an account
3. Create an API token in settings

#### Step 2: Create App Spec

Update `app.yaml` with your GitHub username and repository name.

#### Step 3: Deploy

```bash
# Install doctl
brew install doctl  # macOS
# OR apt-get install doctl  # Ubuntu

# Login
doctl auth init

# Create app
doctl apps create --spec app.yaml

# Monitor deployment
doctl apps list
doctl apps describe <app-id>
```

#### Step 4: View Logs

```bash
doctl apps logs <app-id> --service backend
```

#### Step 5: Manage DNS

In DigitalOcean dashboard:

1. Add your domain
2. Point to app
3. Wait for DNS propagation (~5 minutes)

---

### Deploy to AWS with ECR

```bash
# Create ECR repositories
aws ecr create-repository --repository-name universalpredict-backend
aws ecr create-repository --repository-name universalpredict-frontend

# Build and push images
docker build -t universalpredict-backend ./backend
aws ecr get-login-password | docker login --username AWS --password-stdin <your-ecr-url>
docker tag universalpredict-backend:latest <your-ecr-url>/universalpredict-backend:latest
docker push <your-ecr-url>/universalpredict-backend:latest

# Deploy with ECS/Fargate/CloudFormation
# (See AWS documentation for full setup)
```

## GitHub Actions CI/CD

The repository includes automated workflows:

### Run Tests (on every push)

`.github/workflows/test.yml` automatically:
- Runs backend tests
- Runs frontend tests
- Uploads coverage to Codecov

### Deploy to Railway (on push to main)

`.github/workflows/deploy-railway.yml` automatically:
- Builds Docker images
- Deploys to Railway

### Deploy to DigitalOcean (on push to main)

`.github/workflows/deploy-digitalocean.yml` automatically:
- Builds Docker images
- Pushes to Docker Hub
- Updates DigitalOcean app

#### Setup GitHub Secrets

In your repository settings, add these secrets:

```
RAILWAY_TOKEN: (from railway.app)
DIGITALOCEAN_ACCESS_TOKEN: (from digitalocean.com)
DOCKER_USERNAME: (your Docker Hub username)
DOCKER_PASSWORD: (your Docker Hub password)
DIGITALOCEAN_APP_ID: (your DO app ID)
```

## Troubleshooting

### Models Not Loading

```bash
# Check models path
docker-compose exec backend ls -la /app/lightgbm-repo/models/

# Check logs
docker-compose logs backend | grep "Error loading"

# Verify repo clone
docker-compose exec backend git -C /app/lightgbm-repo log -1
```

### Database Connection Error

```bash
# Check PostgreSQL is running
docker-compose exec postgres psql -U universalpredict -c "SELECT 1;"

# Reset database
docker-compose down -v
docker-compose up -d postgres redis
docker-compose up backend
```

### Port Already in Use

```bash
# Find process using port
lsof -i :8000  # Backend
lsof -i :3000  # Frontend
lsof -i :5432  # PostgreSQL

# Kill process
kill -9 <PID>
```

### Redis Connection Error

```bash
# Check Redis is running
docker-compose exec redis redis-cli ping

# Reset cache
docker-compose exec redis redis-cli FLUSHALL
```

### Permission Issues

```bash
# Fix volume permissions
sudo chown -R $USER:$USER .

# Rebuild containers
docker-compose down
docker-compose up -d --build
```
