## Step 2: Update Configuration

### 1. Edit `.env` file

```bash
# Copy example env file
cp .env.example .env

# Edit with your settings
nano .env  # or use your preferred editor
```

**Important fields to update:**

```env
# Your LightGBM repo (where your models are)
LIGHTGBM_REPO_URL=https://github.com/yourusername/your-lightgbm-repo.git
LIGHTGBM_REPO_BRANCH=main

# JWT Secret (generate a new one)
JWT_SECRET_KEY=your-secure-random-key-here

# Optional: AWS S3 for model storage
AWS_ACCESS_KEY_ID=your_key
AWS_SECRET_ACCESS_KEY=your_secret
```

### 2. Update Docker Build Args

In `docker-compose.yml`, update the `LIGHTGBM_REPO_URL`:

```yaml
backend:
  build:
    args:
      LIGHTGBM_REPO_URL: https://github.com/yourusername/your-lightgbm-repo.git
```

## Step 3: Run Locally

### Option A: With Docker (Recommended)

```bash
# Start all services
docker-compose up -d

# Watch logs
docker-compose logs -f backend

# Access
# Frontend: http://localhost:3000
# API: http://localhost:8000
# API Docs: http://localhost:8000/docs
```

### Option B: Without Docker

```bash
# Backend
cd backend
python -m venv venv
source venv/bin/activate  # or: venv\Scripts\activate (Windows)
pip install -r requirements.txt
uvicorn app.main:app --reload

# Frontend (in new terminal)
cd frontend
npm install
npm start
```

## Step 5: Deploy to Railway

### 5A: Connect GitHub

1. Go to https://railway.app
2. Sign up with GitHub
3. Click "New Project" → "Deploy from GitHub repo"
4. Select your `universalpredict` repository

### 5B: Add Environment Variables

In Railway dashboard:

```
DATABASE_URL=<auto-generated>
REDIS_URL=<auto-generated>
JWT_SECRET_KEY=your-secure-key
LIGHTGBM_REPO_URL=https://github.com/yourusername/your-lightgbm-repo.git
LIGHTGBM_REPO_BRANCH=main
```

### 5C: Deploy

```bash
# Install Railway CLI
npm install -g @railway/cli

# Login
railway login

# Deploy
railway up

# View your app URL
railway open
```

**URL will look like:** `https://yourapp-production.up.railway.app`

## Step 6: Deploy to DigitalOcean (Optional)

### 6A: Create Docker Hub Account

If you don't have one:
1. Go to https://hub.docker.com
2. Sign up
3. Create access token in settings

### 6B: Add GitHub Secrets

In your GitHub repo settings → Secrets:

```
DIGITALOCEAN_ACCESS_TOKEN=<your-do-token>
DOCKER_USERNAME=<your-docker-username>
DOCKER_PASSWORD=<your-docker-token>
DIGITALOCEAN_APP_ID=<your-app-id>
```

### 6C: Create DigitalOcean App

```bash
# Install doctl
brew install doctl  # macOS
# apt-get install doctl  # Ubuntu

# Login
doctl auth init

# Deploy app from spec
doctl apps create --spec app.yaml
```

## Troubleshooting

### Models not loading?
```bash
# Check if repo cloned correctly
docker-compose exec backend ls -la /app/lightgbm-repo/models/

# View logs
docker-compose logs backend | grep -i "error\|loading"
```

### Port already in use?
```bash
# Find what's using port
lsof -i :8000  # Backend
lsof -i :3000  # Frontend

# Kill process
kill -9 <PID>
```

### Database connection error?
```bash
# Reset everything
docker-compose down -v
docker-compose up -d

# Reinitialize
docker-compose exec backend python scripts/setup_db.py
```

### Can't push to GitHub?
```bash
# Verify SSH key
ssh -T git@github.com

# Or use HTTPS with token
git remote set-url origin https://github.com/yourusername/universalpredict.git
```
