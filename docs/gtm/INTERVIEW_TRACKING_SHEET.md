### Print & Carry: Scoring Guide
```
QUALIFICATION SCORE (1-50)

Problem Clarity (1-10):
1-3: Vague, customer unsure
4-6: Clear to them, unclear to you
7-8: Very clear to both
9-10: Crystal clear, obvious pain

Pain Level (1-10):
1-3: Nice to have
4-6: Should solve
7-8: Must solve
9-10: Urgent (losing $ daily)

Budget (1-10):
1-3: No budget
4-6: Budget exists but tight ($<100/mo)
7-8: Good budget ($100-500/mo)
9-10: Significant budget (>$500/mo)

Urgency (1-10):
1-3: Not urgent ("next year")
4-6: Somewhat urgent ("next quarter")
7-8: Very urgent ("next month")
9-10: Critical ("this week")

Decision Speed (1-10):
1-3: Needs 5+ approvals, 3+ months
4-6: Needs 2-3 approvals, 1-2 months
7-8: Mostly their call, 2-4 weeks
9-10: They decide, <1 week
```

## 🔍 COMMON PATTERNS (What to look for)

### Green Flag Patterns ✅
```
✅ "We currently [waste 3 hours/week]"
   → Clear time cost

✅ "Last month we [lost $50K]"
   → Clear financial cost

✅ "We've tried [3 different tools]"
   → Problem is worth solving

✅ "If we could [solve this], it would be worth $[X]"
   → They've thought about value

✅ "We need to solve this [this quarter/month]"
   → Urgency exists

✅ "Can I try [your solution] next week?"
   → Ready to act now
```

### Red Flag Patterns ❌
```
❌ "That's nice but we don't really [use/need] that"
   → Not a priority for them

❌ "We might solve this sometime [next year]"
   → Low urgency

❌ "Our budget is basically [zero]"
   → Can't pay even if they want to

❌ "Sounds like a cool feature"
   → Treating as feature, not solution

❌ "We'd need to ask [5 people]"
   → Slow decision making

❌ "We've never really thought about [the problem]"
   → Not top of mind
```

## 📋 DATA TO COLLECT (Per Interview)

| Field | Why Important | Where to get it |
|-------|---------------|-----------------|
| Job Title | Understand persona | Ask directly |
| Company Size | Affects budget/process | "How many people?" |
| Industry | Affects pain points | "What industry?" |
| Current Solution | What to replace | "How do you solve this now?" |
| Time Spent | Calculate cost | "How much time/week?" |
| Financial Impact | Justify pricing | "What's the cost when this fails?" |
| Budget | Know pricing ceiling | "Budget for a solution?" |
| Timeline | Know urgency | "When would you want to solve this?" |
| Decision Process | Know sales cycle | "Who decides purchases?" |
| Would Pay? | Know if viable | "Would you pay $X/month?" |
| Why/Why Not | Understand objections | "Why/why not?" |

## 🎯 WEEKLY RITUAL (Friday, 30 min)

**Every Friday at 3pm:**

```
Step 1: Review all interviews (5 min)
- Read each summary
- Highlight key quotes
- Look for new patterns

Step 2: Update metrics (10 min)
- Calculate averages
- Count % saying yes to each question
- Look for trends

Step 3: Make decision (10 min)
- Are we seeing pattern? (need 70%+ same problem)
- Should we continue or pivot?
- What's next week's focus?

Step 4: Update plan (5 min)
- Schedule next batch of interviews
- Note any key learnings
- Send to accountability partner
```
