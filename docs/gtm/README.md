# Go-to-market material

These are **plans and templates, not descriptions of the product**. Nothing in
this directory should be read as a statement about what the software does — for
that see the root [README.md](../../README.md) and
[ARCHITECTURE.md](../../ARCHITECTURE.md).

They are kept because the content is reusable and does not duplicate anything
in the engineering docs. They are unversioned thinking: dates, targets and
revenue figures in them are aspirational and were not achieved by any code in
this repository.

| File | What it is |
|---|---|
| [CHURN_PREDICTION_PLAYBOOK.md](CHURN_PREDICTION_PLAYBOOK.md) | Target persona, positioning and outbound angles for the churn use case |
| [CUSTOMER_INTERVIEW_TEMPLATE.md](CUSTOMER_INTERVIEW_TEMPLATE.md) | Question script for discovery interviews |
| [INTERVIEW_TRACKING_SHEET.md](INTERVIEW_TRACKING_SHEET.md) | Template for logging interviews and spotting patterns across them |
| [PRICING_STRATEGY.md](PRICING_STRATEGY.md) | Candidate pricing tiers and a framework for testing them. Hypotheses, not live pricing |
| [PMF_90_DAY_EXECUTION.md](PMF_90_DAY_EXECUTION.md) | A 90-day product-market-fit plan, with the discovery checklists merged in |

Several near-duplicate versions of this material (`PMF_STARTER_GUIDE.md`,
`EXECUTION_CHURN_DISCOVERY.md`, `LIGHTGBM_PARALLEL_EXECUTION.md`,
`MOAT_BUILDING.md`, `TEAM_HIRING_PLAN.md`, `RETENTION_ONBOARDING.md`,
`COMPLETE_ACTIVATION_FLOW.md`) were removed; they restated the above with
different numbers.
